3. HOW TO RESTORE AND RUN ON ANY MACHINE IN THE FUTURE
--------------------------------------------------------------------------------
Step 1: Clone the repository
  git clone https://github.com/aryan-guptta-2007/Sentinelai.git
  cd Sentinelai

Step 2: Setup (Windows)
  powershell -ExecutionPolicy Bypass -File utils\setup.ps1
  # Or manually:
  python -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt

Step 2: Setup (Linux)
  bash utils/setup.sh
  # Or manually:
  python3 -m venv .venv
  .venv/bin/pip install -r requirements.txt

Step 3: Verification
  # On Windows:
  .\.venv\Scripts\python.exe sentinel.py check
  .\.venv\Scripts\python.exe -m pytest -q

  # On Linux:
  .venv/bin/python sentinel.py check
  .venv/bin/python -m pytest -q

Step 4: Running SentinelAI
  # Run demo (safe simulated attacks):
  .\.venv\Scripts\python.exe sentinel.py demo

  # Run real intrusion detection & response:
  .\.venv\Scripts\python.exe sentinel.py run

  # Get dashboard URL and token:
  .\.venv\Scripts\python.exe sentinel.py token

  # Generate standalone HTML report:
  .\.venv\Scripts\python.exe sentinel.py report --hours 24
